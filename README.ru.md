# Часы Wearfit Pro (Bluetrum XunLong) — реверс BLE-протокола

[English version](README.md)

Реверс-инжиниринг бюджетных смарт-часов, работающих с приложением **Wearfit Pro**
(`com.wakeup.howear`). Подтверждено на **Wearfit X10** (`v.13YM0042-1_[fwk_1.11]_[sdk_1.11]_[app2.11]`,
код модели **5911**, прошивка **1.13**) и, скорее всего, применимо ко всему семейству
клонов Apple Watch на этом приложении: HK89, X8 Ultra, T800 Ultra, A9/A10 и т.д.
Платформа: **Bluetrum 中科蓝讯 «XunLong»**.

> **Коротко:** часы полностью управляются с ПК по BLE — хендшейк, синхронизация времени,
> «найти часы» (реально звенит!), формат данных здоровья (пульс / SpO2 / давление) расшифрован.
> Внутри — рабочий Python-клиент. Никакой криптографии и подписей.

## Зачем

Официальное приложение — реклама, обязательный аккаунт и китайское облако.
Этот проект документирует протокол, чтобы можно было сделать свой чистый клиент,
заливать свои циферблаты или писать свою прошивку для часов, которые тебе принадлежат.

## Что уже работает

- ✅ Полный хендшейк с ПК (`tools/channel.py`)
- ✅ Команды исполняются: синхронизация времени, «найти часы» (звенит+вибрирует), настройки
- ✅ Расшифровка инфо: версия прошивки, код модели, биты способностей
- ✅ Формат фреймов здоровья: пульс / SpO2 / давление / стресс / шаги
- ✅ Собраны дампы циферблатов .bin; найден публичный CDN циферблатов
- ⏳ Паковщик своих циферблатов (в процессе)
- ⏳ Свой Android-клиент (протокол доказан, дальше реализация)

## Быстрый старт

Нужны: Linux с BlueZ, Python 3.10+, [`dbus-fast`](https://pypi.org/project/dbus-fast/).

```bash
pip install dbus-fast
python tools/interrogate.py   # подключение, хендшейк, допрос часов
```

Часы не должны быть заняты телефоном — их BLE-стек обслуживает одного клиента.

## Главные находки (коротко)

1. Командные фреймы начинаются с **`0xAB`** (расширенное семейство `0xEA`) — не `0xAA`.
2. Ответы доставляются **только при подписке через `AcquireNotify`** (сырой сокет).
   BlueZ `StartNotify` отрабатывает успешно, но данные на этих часах молча не приходят.
3. Поле длины = число байтов после поля длины; **весь фрейм = len + 3**.
4. Хендшейк несёт модель телефона и id пользователя; часы отвечают версией прошивки,
   кодом модели и битами способностей.
5. Синхронизация здоровья — класс `0x51`: пульс, SpO2, давление — обычные байты.
6. OTA (Bluetrum ABOta) льёт сырой `.bin` — без контейнера и подписей на стороне приложения.

Все детали с байтами — в [PROTOCOL.md](PROTOCOL.md).

## Границы железа (X10)

| Есть | Нет |
|---|---|
| Экран 368×448, динамик, вибро | WiFi, GPS-чип, NFC (не подтверждён), |
| Пульсометр (IR-режим), SpO2, расчётное давление | температура тела, ECG |
| Акселерометр, звонки по классическому BT (HFP) | JS-движок (мини-приложений нет), интернет |

Расшифровка битов способностей — в [HARDWARE.md](HARDWARE.md).

## Дисклеймер

Образовательные цели, только для устройств, которыми вы владеете. Документация
интероперабельности — проприетарный код вендора не включён и не распространяется.
Прошивка может окирпичить часы; официальное приложение остаётся безопасным путём.
